# Every number word in the site's own prose, one line each:
#   <path under site/> <word> <total> counted=<n> [audited-at-<project>=<pin>]
#
# A count a machine can measure never appears here, because it never appears
# on the page: it is a __COUNT_<source>_<spelling>__ placeholder that
# scripts/stamp-counts.py fills in from the pinned checkout or from the sample
# index the build wrote. This list is for the rest — the reading of a
# population rather than a measurement of one, and the number that measures
# no population at all.
#
# `counted=<n>` says how many of the file's occurrences state a number a pin
# bump can still move. Those get a clock, and the bump moves past it the way
# it does for a version literal: re-read the sentence against the thing it
# counts, then re-stamp. The rest are frozen — a historical measurement, a
# property of the language, a duration — and carry no clock, because there is
# nothing for a pin to move.
#
# Three projects can move a number here, so there are three clocks:
#   audited-at-wolf=    the compiler's releases, its corpus, its documents
#   audited-at-lupin=   what the interpreter in the tab answers
#   audited-at-book=    the book, which publishes no version, so its pin
#
# A count a machine CAN measure but that no source here could reach was the
# ww20 finding: the distance in commits from the specification revision the
# interpreter was built to, to the commit the compiler was tagged at. It is a
# `__COUNT_speccommits_word__` stamp now, counted with git over the two pinned
# gitlinks, and it is on both /install/ and /play/ — which is why neither
# carries a number word for it.
#
# The vocabulary starts at five. One through four are ordinary English on this
# site and enumerating them would produce a file nobody reads; the defect this
# list exists for (wolf-web#17 — /play/ said TWELVE net programs for two
# releases while the corpus carried thirteen and then sixteen) lived well
# above that line. See scripts/check-counts.py.
#
# What each live entry was read against, at this pass:
#   docs/     `seven items` — docs/api/index.json, two modules, 2 + 5 items
#   /         `five packages on the AUR` — the live AUR, five results
#   / and /install/ the five named Windows refusals — the windows job proves
#             each one by name, and its header comment counts them
#   /install/ `thirty-six rows` — docs/platforms.md, "the 36 rows the native
#             lane does not execute here are the same 36 ... on macOS"
#   /play/    `five` new `Map` witnesses and `nine` running `if_then`
#             witnesses — NEW at ww26c, and both are census counts measured
#             through the module this build publishes, not read off a
#             changelog. v0.2.11 brings 24 new `phase: run` corpus files; of
#             the five `memory/map_*` witnesses three run in the tab and two
#             do not, and all nine running `grammar/if_then_*` witnesses run.
#             They ride the LUPIN clock rather than the wolf one even though
#             the corpus that defines them is the compiler's, because what
#             makes either number move is the mirror catching up: when lupin
#             takes s152 and s155 the five becomes five-of-five and the
#             parting closes. Both were re-derived from the census at this
#             bump, not copied from the sprint's prediction — the prediction
#             said none of the five would run and three of them do.
#   /play/    `Seven tiers` — the census's own reason strings: tasks, procs,
#             time, the process trio, net, os_random, os_signal_listen. The
#             filesystem tier and the module graph are declined too and are
#             not in the seven, because the sentence counts what a terminal
#             lupin serves and this build does not. Re-read at lupin 0.1.31:
#             all seven reasons are still in the census, unchanged in number
#             and in wording. The one verdict 0.1.31 moved left the
#             `unsupported` class altogether (`strings/concat_mix_char.lu`),
#             so it took no reason string with it.
#   /play/    `Five` corpus programs part — RETIRED at ww21. lupin 0.1.30
#             mirrors three of the four rulings the table was built on, so it
#             is one row now (concat_mix_char, wolf-interp#78) and one is
#             ordinary English: this file's vocabulary starts at five, and a
#             number below that line gets no entry. The row that remains is
#             re-measured through the module the build publishes, the way the
#             five were. At ww23 the row is gone too — the interpreter serves
#             `str + char` now — and the table itself is retired: the census
#             moved exactly one verdict and it was that one, so /play/ states
#             a parting of none in prose and carries no number at all.
#   /reading/ 33 chapter files at book d3536df. ALL FOUR STAND, for the third
#             bump running, and no two of the three stood for the same reason.
#             bs40 rewrites chapter 5 on the map alone — 307 lines, the largest
#             single hunk the book has taken at a site bump — and touches ch01,
#             ch03, ch04, ch06, ch10-ch15, ch33, four back-matter pages, the
#             exercise corpus, the vendored spec artifacts and two xtask files.
#             book/SUMMARY.md is not in it, and neither is ch21, ch25, ch29 or
#             any chapter of part 5. Three things in the diff could have moved
#             a number here and were checked against the checkout rather than
#             assumed. (1) The colophon IS where "Two chapters and five
#             sections in this edition are reserved" lives — the sentence the
#             written-through figure is the outside view of — and it IS in the
#             diff; its change is confined to the `wolf --version` console
#             block and the paragraph that reads the pair (the compiler's half
#             is a +dev build now, so neither name in the pair is exact and the
#             distance is eighty-four commits, not fifty-one). The reservation
#             sentence and the three lines under it are byte-identical.
#             (2) Chapter 5 is the chapter /reading/ quotes by title in the
#             Foundations line. Its H1 is still `# 5. Collections and generics`
#             and all five `## 5.N` headings survive the rewrite, moved down
#             the file and not renamed or merged, so the dd needs no edit and
#             ch05 does not join the held set. (3) ch33 is in the diff and
#             /reading/ quotes its title twice; the change is seven `0 - 1`
#             sites respelled `-1` (wolf-book#31) and nothing else.
#             The counts themselves, measured at the checkout: 33 entries in
#             SUMMARY.md; ch29 still the one chapter reserved whole and ch25
#             still the one written to a single section, which are the two
#             /reading/ names, so thirty-one are written through; ch21 still
#             §21.1, §21.2 and §21.4 with §21.3 and §21.5 held, which its own
#             closing sentence still calls five; chapters 26-32 still six
#             programs and a coda.
#             A CORRECTION to what this entry said at d001309: ch29 is NOT the
#             only chapter with no `## N.M` heading of a given kind and ch25 is
#             NOT the only one carrying a single numbered section. ch13 carries
#             §13.2 alone (§13.1 is vacant by its own rp01 hold) and ch23
#             carries two of four. Both have been that way at every pin this
#             file has audited, and both are still written through by the rule
#             /reading/ states beside the figure — a chapter that holds
#             something back says so on its own page, and ch21 is counted
#             written through on exactly that basis. The figure is 33 minus the
#             two the page names; the old parenthetical defended the right
#             number with the wrong test.
#             At 3edba7d two of the four moved, when ch33 and Appendix E
#             arrived; at f1eb3bb, d001309 and here none did. A clock that
#             reddens when nothing moved is the clock working — the re-read is
#             the point, not the edit.
#   /         `seven characters` — NEW at ww24. The commit a development
#             build's version string carries is seven hex characters from
#             every clone, by decision (wolf-lang#301), rather than whatever
#             `git rev-parse --short` picks from the object count. It is a
#             ruling and not a measurement, so it is a literal — but it rides
#             the wolf clock with counted=1 rather than being frozen, because
#             the thing that would change it is exactly a release, and a
#             sentence quoting a width the toolchain has stopped using is the
#             class of rot this file exists for.
#
# The wolf clock moved at ww24 (0.2.9 -> 0.2.10) and the six wolf entries were
# re-read. `five packages on the AUR` was read live and is still five —
# wolf-lang, wolf-lang-bin, lupin, lupin-bin, lobo-bin. The five named Windows
# refusals are unchanged, because v0.2.10 is a language release and touches no
# platform surface; the windows job's header still counts the same five.
# `thirty-six rows` holds: docs/platforms.md is byte-identical at this tag.
# /docs/'s `seven items` holds: docs/api/index.json is still the two-module
# `demo/doc` fixture, 2 + 5. /play/'s `Seven tiers` rides the LUPIN clock and
# was not asked this pass; the census confirms it anyway, all seven reason
# strings present and unchanged in wording at 308 phase:run programs.
#
# CHANGELOG.md is not under site/, and it is served prose all the same: it
# renders to /changelog/site/ (wolf-web#27). Every line below is counted=0 and
# carries no clock, because an entry records what one wave measured at one set
# of pins and no later bump can make that false. What the lines buy is the
# thing that was missing: a number written into a served sentence costs an
# allowlist line, so its author derives it. ww24's entry claimed three counts
# of its own allowlists in a paragraph about counting, two of them wrong, and
# the build was green from its first commit to its last.
