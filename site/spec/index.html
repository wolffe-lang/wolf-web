specification

Normative. Both implementations are readings of it.

wolf install playground the book docs spec changelog

These documents are the language. The compiler and the reference interpreter share no code; what they share is this specification, the conformance corpus, and the protocol they are compared through. When the two disagree about a program, the specification is what gets read, and sometimes amended.

Every document carries clause anchors in brackets, spelled like [mem.region.create.3]. A diagnostic cites one, a trap cites one, a corpus program declares which ones it conforms to, and the anchor index is checked against the prose so a citation cannot point at a clause that was renamed. Files are served as plain text.

The documents

01. Surface Grammar (__KIB_spec/01-grammar.md__ KiB)
Lexing, the mode stack that lets strings nest inside strings, the expression grammar and its precedence tiers, statement and item forms, and the ambiguity rulings. Status: normative, grammar/1, declared at v0.1.0 and held additive-only through the 0.1.x line; at v__WOLF_VERSION__ it is still grammar/1 — a removal or narrowing would be a grammar/2 act, and none has been taken. This release widens it, which is the additive direction: the pattern grammar gains a range form, [gram.pat.range], so lo..hi and lo..=hi over integer and char literals are patterns wherever a pattern goes, composed with or-patterns, with guards and with @-bindings. Both ends must be literals and neither may be left off, because an open end is how a slice is spelled — and the refusal is required to say the word "range", which is the papercut the clause was written for. It rules the rest of the shape too: overlap is legal and the first arm wins, an arm nothing can reach is E0802, a range no value can match is E0815, and exhaustiveness computes no union, so an integer or char column stays infinite and still wants a _. Every program that parsed before still parses. Anchors [gram.*].
02. Memory Model (__KIB_spec/02-memory-model.md__ KiB)
Regions, ownership tiers, moves, freezing, the shared and handle edges, provenance, and the closed list of rows that are undefined behavior with the optimization each one licenses. The interpreter implements this document as a dynamic machine; the compiler implements a static approximation of it. This release adds [mem.str.imm]: a str never changes after it is built and a slice of one is a view, so there is no place on the left of s[i..j] = … — a rule rather than a thing the backend has not got to, and E0416 says so. Anchors [mem.*].
03. Concurrency (__KIB_spec/03-concurrency.md__ KiB)
Structured tasks, supervised procs, channels with region transfer, select, the memory model's happens-before rules, and the deterministic schedule a seed selects. Written in the shape of the Go memory model document, with the advice in front of the formalism. At this release [conc.chan.close] finally types what it had described for two: send is () ! {closed, cancelled}, the same two tags the receive side carries, because a send blocked on a full buffer is a cancellation point too. Anchors [conc.*].
04. ABI (__KIB_spec/04-abi.md__ KiB)
Layout, calling convention, and the foreign boundary, differentially fuzzed against platform C compilers. Anchors [abi.*].
05. Conformance (__KIB_spec/05-conformance.md__ KiB)
What makes the rest of it testable: clause anchors, test tagging, the closed trap vocabulary, and coverage reporting. The interpreter reads only the specification and the corpus, and this document is part of that sealed interface. Its own register of anchor namespaces has been wrong in both directions, and is checked in both now. At v0.2.6 it named seven while the documents were publishing anchors in eleven, and the four unlisted ones were appended. At v0.2.7 the mirror closed: 07-schedule-points.md had been declaring seven [sched.*] anchors that no register carried, so no extractor read the document and no gate anywhere held an opinion, while the runtime cited four of the seven from live scheduler code. sched is registered now and its anchors are published, 424 to 431. Neither change renumbered anything, because a published anchor is never moved and the citations that would have had to move number in the thousands. Anchors [conf.*].
06. Differential Protocol (__KIB_spec/06-differential-protocol.md__ KiB)
The two-implementation contract, and the only shared artifact between the tracks. It defines the observation record: the phase reached, the verdict, the diagnostics as code and span with no message, and the output digest. Diagnostic wording is deliberately excluded, because wording is a per-implementation concern and comparing it would manufacture disagreements. The playground can show you a record for any program you run. Anchors [proto.*].
07. Schedule Points (__KIB_spec/07-schedule-points.md__ KiB)
Where a schedule can make a decision, and the numbering a replayable counterexample uses. Normative for shape and vocabulary, and append-only from here. Its [sched.*] anchors are published in the index as of v0.2.7; before that they were declared here and carried by no register, so a program citing one was rejected for citing a clause that existed. Anchors [sched.*].
08. Packages (__KIB_spec/08-package.md__ KiB)
The package layer's formats, under one covenant: reading the dependency graph never executes anything — no build scripts, no hooks, no fallbacks. The manifest is data, resolution is minimal-version, and the registry entry's shape is fixed before any hosted registry exists to serve it. Anchors [pkg.*].
09. Constant-Time (__KIB_spec/09-constant-time.md__ KiB)
#[consttime] as a verified contract: secret-tainted data cannot decide a branch, index memory, pick a call target, or feed a variable-time instruction, refused fail-closed on every lane in every build mode. Anchors [ct.*].
10. Types (__KIB_spec/10-types.md__ KiB)
The numeric-literal typing rules written down in one place: how a bare literal takes its type, int adopting float in mixed arithmetic, and the casts that trap instead of wrapping. It is also where byte is declared — the 8-bit unsigned octet the toolchain gained at v0.2.4, with the clauses for its cast in both directions, the widening its operators do before they compute, and what an interpolation hole prints. It is the document this release grows most. [type.unit] writes down what a unit context is — a loop body, an else-less if, a unit function — and rules that a !() tail in one is a warned discard rather than a mismatch, with the counter-case for a task closure whose scope consumes the row. [type.fn.ret] checks a body's tail against the declared result and [type.row.operand] refuses a bare row as an operand; both were already enforced and neither was written. Anchors [type.*].
11. OS surface (__KIB_spec/11-os.md__ KiB)
The operating-system surface the builtin tier exposes. v1 covers signal reception and OS randomness — the latter with no fallback and no seeding, so failure traps honestly. The socket section opened at v0.2.4 with unix-domain streams in the TCP pair's shape and the error rows that tell an unserved host apart from a bad path; at v0.2.5 it gained what a serving loop needs — one wait over a whole set of handles ([os.net.wait]), a listener several processes may hold at once ([os.net.listen.opts]), descriptors handed down across a spawn by position ([os.proc.inherit]), and the count of cores this process may be scheduled on ([os.cpus]). At v0.2.6 it stated what those hands actually see when a connection arrives ([os.net.accept]): a wake is not a connection, so the hand that loses the race carries no answer and waits again against the budget its deadline armed, in the runtime's wait rather than the kernel's. At v0.2.8 it stated when the syscall happens ([os.net.io]: a parking call tries the syscall before it waits, and waits only when the kernel says it would block), and gained three calls that name what a serving loop was doing by hand — the Nagle switch every stream is handed with ([os.net.nodelay]), the gathered write ([os.net.writev]), and one metadata read on an open handle ([os.fs.fstat]) in place of a path stat per fact. The first of those moved a cost and no row; the other three were new surface, and every one of them serves every tier-1 host. This release does not touch the document. Anchors [os.*].

Reading it against a program

The conformance corpus is the specification's working end. Each program states its own expected outcome in a header directive and lists the clauses it conforms to, and CI in the compiler repository checks the claim on both implementations. The playground loads __COUNT_samples_odd__ of those programs with their headers intact, which is the shortest path from a clause to a program that exercises it.

Copied from a pinned wolf-lang checkout on every deploy. Every size on this page is measured from that checkout at build time, not written here by hand.
