Every repository in the project keeps a CHANGELOG.md at its root, maintained as part of the work rather than reconstructed after it. The pages below are those files, rendered from the same pinned checkouts the rest of this site is built from — so a page here can only show what the pins carry: never wrong, only honestly behind. A pinned repository that does not carry a changelog yet gets a page that says exactly that.
